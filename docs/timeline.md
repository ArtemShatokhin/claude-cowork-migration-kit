# The dated timeline

Kortix is open source. This page is the dated record of what happened to Claude Cowork, and every entry names the page it came from. The short version: the product a team was using in August 2026 still runs in October 2026, under a different name, and no step in between moved a single file on the team's behalf.

## 12 January 2026: Cowork arrives as a research preview

Cowork launched as a research preview for Claude Max subscribers in the macOS desktop app ([VentureBeat](https://venturebeat.com/technology/anthropic-is-killing-off-cowork-and-folding-it-into-claude-launching-claude-docs-and-claude-slides)). It was built on the agentic architecture behind Claude Code, and packaged for people who did not work in a terminal. The product was narrow. One operating system, one plan, desktop only.

## Before 16 September 2026: Cowork is on every paid plan

By the morning of the announcement, Cowork ran on Claude Desktop for every paid plan, and on web and mobile for Pro, Max and Team. Enterprise accounts had it where an admin enabled it, and the Claude in Chrome side panel carried it for Max and Team subscribers ([VentureBeat](https://venturebeat.com/technology/anthropic-is-killing-off-cowork-and-folding-it-into-claude-launching-claude-docs-and-claude-slides)). Desktop carried the extra capabilities. Claude could read local files there and drive a browser on the person's own machine.

## 9 September 2026: the legacy memory export window closes

Anthropic rebuilt its memory system and migrated accounts off the legacy experience. The Help Center told anyone who thought something had been forgotten to open Settings → Memory, where "until September 9, 2026, you will see the option to export your legacy memory" ([Claude Help Center](https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context)). That date has passed. The window for pulling a legacy memory file out of the account closed a week before the merge, which is worth knowing if a team is still deciding when to start its inventory.

## 16 September 2026: Anthropic folds Cowork into Claude

"Anthropic is killing off its Claude Cowork brand and product as a separate experience, instead folding all its capabilities back into the default Claude chatbot interface" ([VentureBeat, 16 September 2026, 9:32 am PT](https://venturebeat.com/technology/anthropic-is-killing-off-cowork-and-folding-it-into-claude-launching-claude-docs-and-claude-slides)). The same release put Claude Docs and Claude Slides into beta and moved Claude Design inside a conversation.

## 16 September 2026: the carry-over list, in Anthropic's words

Anthropic said that people and enterprises already working in Cowork "retain their chats, projects, artifacts, connectors and skills" ([VentureBeat](https://venturebeat.com/technology/anthropic-is-killing-off-cowork-and-folding-it-into-claude-launching-claude-docs-and-claude-slides)). Nothing was handed to the customer to hold. The list describes what stays inside the Claude account. That is the distinction this kit turns on.

## 16 September 2026: the toggle starts to disappear

The Chat-versus-Cowork choice under the message box goes away as the rollout reaches each account ([VentureBeat](https://venturebeat.com/technology/anthropic-is-killing-off-cowork-and-folding-it-into-claude-launching-claude-docs-and-claude-slides)). Claude then decides from the prompt whether a request is a quick answer or a longer job. Anthropic also said the Cowork name itself "will eventually disappear", while Claude Code stays a separate product for developers.

## From 16 September 2026: the rollout order

Pro and Max accounts on web, desktop and mobile moved first, with Team and Free to follow ([VentureBeat](https://venturebeat.com/technology/anthropic-is-killing-off-cowork-and-folding-it-into-claude-launching-claude-docs-and-claude-slides)). On Enterprise plans the unified experience is a beta that an owner turns on. The Help Center describes it as "rolling out gradually to Pro and Max plans" ([Claude Help Center](https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork)). Accounts on the same plan can therefore sit in different waves.

## 16 September 2026: what did not change

The permission modes stayed. Cowork still asks before it acts under Manual, keeps working and reviews each action under Auto, and runs without asking under Skip ([Claude Help Center](https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork)). An organization can still turn off web search for Cowork and chat under Organization settings → Capabilities. The control is a mode a person picks in the product, and it lives there rather than in a file the team reads.

## 20 October 2026: the Help Center still calls it a rename

The page a reader lands on today opens with "Note: Claude Cowork is now just Claude" ([Claude Help Center](https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork), checked 20 October 2026). It then calls the change gradual, and a beta where an Enterprise admin enables it. Work now runs in the cloud "in beta on Team and Enterprise plans", and sessions and files are "saved to your Claude account".

## 20 October 2026: the record exists, on Anthropic's side

Anthropic's Compliance API documentation lists the endpoints that return "transcripts of Cowork sessions started on claude.ai web or mobile, which run in the cloud in Anthropic-managed environments" ([Anthropic documentation](https://platform.claude.com/docs/en/manage-claude/compliance-api), checked 20 October 2026). The same set of endpoints covers local sessions, captured while a person is signed in to an Enterprise account. The content endpoints "serve Claude Enterprise data only". The record is real, and it is Anthropic's to serve.

## What the dates add up to

Between 12 January and 20 October, the surface changed name, plan, placement and owner of the decision about what counts as a job. The work stayed put. A team reading this timeline for a migration plan gets one useful date out of it: the day it decides to write its setup down. Kortix, the open-source AI Operating System, exists so that date has somewhere to land.
